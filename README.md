# 💅 Алина × Наташа — общий кошелёк

Telegram-бот для совместного учёта расходов, квартиры, коммуналки и взаимных долгов.

## Возможности
- добавление расходов;
- категории: общак, хата, коммуналка, продукты, развлечения, другое;
- история текущего месяца;
- отчёт и баланс за месяц;
- расчёт, кто кому должен при делении 50/50;
- доступ только по Telegram ID.

## Переменные окружения
- `TOKEN` — токен Telegram-бота;
- `ALLOWED_USERS` — Telegram ID двух пользователей через запятую;
- `DB_PATH` — путь к SQLite базе (по умолчанию `expenses.db`).

Команда запуска: `python bot.py`.
